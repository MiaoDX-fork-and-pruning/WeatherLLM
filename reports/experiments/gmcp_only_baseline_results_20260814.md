# GMCP-only Baseline 训练与评估结果

**日期**: 2026-08-14
**模型**: PhyDiff-Net GMCP-only（467M 参数，hidden_dim=192）
**训练数据**: 2000-2001 年 GMCP 6h 累计降水（2908 样本）
**验证数据**: 2002 年（1444 样本）
**测试数据**: 2003 年前 50 个样本
**损失函数**: GMCPExtremeLoss（归一化 MSE + 物理空间 CSI + 极端加权）

## 3. 分析

### 积极方面
1. **轻-中雨有检测能力**：CSI 0.12-0.23，HSS 0.21-0.34，模型能识别降水发生区域
2. **RMSE 较低**：0.805 mm/6h（降水均值 0.59mm/6h），连续值预测合理
3. **相关性中等**：0.483，模型捕捉了降水空间模式的大体结构
4. **Bias 轻微低估**：-0.058，与极端事件难以预测一致

### 主要不足
1. **极端事件完全失败**：≥25mm CSI≈0，F1≈0。根因：
   - 仅 3 epoch 训练，极端事件样本极少（0.004%）
   - GMCP-only 模式无大气环流输入，缺乏极端降水的物理前兆信息
2. **大雨 FAR 极高**：0.972，几乎所有大雨预测都是误报
3. **Area Bias 偏低**：0.043-0.44，模型倾向于低估降水范围

### 与 SOTA 目标的差距

| 指标 | 目标 | 当前 | 差距原因 |
|------|------|------|----------|
| 极端 CSI | >0.5 | 0.001 | 无 ERA5 输入 + 训练不足 |
| 强降水 POD | >0.8 | 0.001 | 同上 |
| 强降水 FAR | <0.3 | 0.972 | 同上 |
| RMSE | 降 10-15% | 0.805 | 基线值，需对比 GenCast |

---

## 4. 结论

本次实验**验证了完整的「数据→训练→评估」闭环**，产出了一个可用的 GMCP-only baseline。结果符合预期：

- **管道层面**：全部打通，从 6h 标签生成到训练到评估全链路可用
- **模型层面**：轻中雨有基本预测能力，但极端事件需要 ERA5 大气输入和更长训练
- **下一步关键**：引入 ERA5 数据进行双源融合训练，这是提升极端事件预测的必经之路
