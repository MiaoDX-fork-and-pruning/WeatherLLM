**项目报告 - 供导师审阅**

**日期**：2026年6月15日  
**团队**：PhyDiff-Net研究组

## 一、研究背景与意义

### 1.1 气象预报AI化趋势

天气预报正在从传统的数值天气预报（NWP）向AI驱动的预报范式转变。2023-2025年间，Google DeepMind的GenCast、GraphCast以及华为的Pangu-Weather等AI天气预报模型在Nature/Science发表，标志着AI气象预报进入了新的阶段。

### 1.2 降水预报的挑战

降水预报是天气预报中最具挑战性的任务之一：
- **极端事件**：暴雨、暴雪等极端降水事件对社会影响巨大
- **稀疏性**：降水事件在时空上高度稀疏
- **物理约束**：需要满足水汽守恒、能量守恒等大气动力学方程
- **概率预报**：需要给出概率分布而非确定性预测

### 1.3 研究目标

本研究旨在设计并实现**PhyDiff-Net**（物理约束扩散网络），在中期全球降水预报任务上超越当前行业最优水平（GenCast），主要目标：

1. **CSI指标**：在0.1mm、1mm、5mm、10mm、30mm等降水阈值上超越GenCast
2. **极端事件**：显著提升对极端降水事件的预报能力
3. **概率校准**：提供可靠的概率预报和不确定性量化

## 二、算法方案：PhyDiff-Net

### 2.1 模型架构概述

PhyDiff-Net是一个基于条件扩散模型的多任务降水预报网络，包含五大核心创新模块：

```
输入：ERA5大气状态 (历史N帧)
        ↓
┌─────────────────────────────────────┐
│  多尺度时空编码器 (Multi-Scale Encoder) │
│  - 3D卷积 + Transformer混合架构      │
│  - 1-3天、3-7天、7-15天多尺度特征      │
└─────────────────────────────────────┘
        ↓
┌─────────────────────────────────────┐
│  物理约束扩散模块 (Physics-Constrained) │
│  - 前向扩散：逐步添加噪声           │
│  - 反向扩散：物理约束引导去噪        │
│  - 水汽守恒约束                     │
└─────────────────────────────────────┘
        ↓
┌─────────────────────────────────────┐
│  极端事件感知分支 (Extreme Branch)    │
│  - 极端阈值自适应检测               │
│  - 极端事件专用损失函数             │
│  - 多任务联合训练                   │
└─────────────────────────────────────┘
        ↓
┌─────────────────────────────────────┐
│  时空异质性建模 (Heterogeneity)       │
│  - 位置感知嵌入                    │
│  - 海拔、纬度、季节等先验特征       │
└─────────────────────────────────────┘
        ↓
输出：降水概率分布 (T+1至T+15天)
```

### 2.2 五大创新点

#### 创新点1：物理约束扩散机制
- **核心思想**：在扩散模型的反向过程中嵌入物理约束，确保生成的降水场满足大气动力学规律
- **约束类型**：水汽守恒方程、连续性方程、热力学方程
- **优势**：相比纯数据驱动方法，生成结果更符合物理规律

#### 创新点2：多尺度时空编码
- **核心思想**：使用不同时间尺度的编码器分别捕捉短期（1-3天）、中期（3-7天）、长期（7-15天）的降水模式
- **技术方案**：3D卷积提取空间特征，Transformer捕捉时间依赖
- **优势**：更全面地表示降水的多时间尺度特征

#### 创新点3：极端事件感知分支
- **核心思想**：设计专门的分支网络检测和预报极端降水事件
- **技术方案**：自适应阈值检测、极端事件专用损失、多任务联合训练
- **优势**：显著提升对极端降水的预报能力

#### 创新点4：时空异质性建模
- **核心思想**：建模降水的时空异质性，考虑不同地理位置的降水特征差异
- **技术方案**：位置感知嵌入、海拔/纬度/季节等先验特征融合
- **优势**：更准确地表示不同区域的降水特征

#### 创新点5：联合概率-确定性优化
- **核心思想**：同时优化概率预测（CRPS）和确定性预测（CSI）
- **技术方案**：多任务损失函数、自适应权重调整
- **优势**：兼顾预报精度和不确定性量化

### 2.3 技术优势

| 维度 | GenCast/GraphCast | PhyDiff-Net |
|------|-------------------|-------------|
| 物理约束 | 无 | 水汽守恒、能量守恒 |
| 极端事件处理 | 无专门设计 | 专用分支+损失 |
| 多尺度建模 | 单一尺度 | 3个时间尺度 |
| 时空异质性 | 无 | 位置感知嵌入 |
| 概率校准 | 基础 | CRPS+CSI联合优化 |

## 三、数据特征获取

### 3.1 训练数据：ERA5再分析数据

**来源**：欧洲中期天气预报中心（ECMWF）  
**分辨率**：0.25° × 0.25°（约25km）  
**时间范围**：1979-2018年（40年）  
**下载方式**：CDS API（需注册账号并接受许可证）

**变量选择**：

| 类别 | 变量 | 层次 | 物理意义 |
|------|------|------|----------|
| **动力场** | u/v风速 | 1000/850/500/200hPa | 大气环流 |
| | 位势高度 | 1000/850/500/200hPa | 天气系统 |
| **热力场** | 温度 | 1000/850/500/200hPa | 热力状态 |
| | 相对湿度 | 1000/850/500/200hPa | 水汽条件 |
| **水汽场** | 比湿 | 1000/850/500/200hPa | 水汽含量 |
| | 可降水量 | 地面 | 整层水汽 |
| **地面场** | 地面气压 | 地面 | 天气系统 |
| | 2m温度 | 地面 | 近地面温度 |
| | 10m风速 | 地面 | 近地面风场 |
| **辐射场** | 向下短波辐射 | 地面 | 能量输入 |
| | 向上长波辐射 | 地面 | 能量输出 |

**预计数据量**：约200GB（压缩后）

### 3.2 评测真值：GMCP降水数据

**来源**：中国气象局国家气象信息中心  
**分辨率**：0.1° × 0.1°（约10km）  
**时间范围**：需要与ERA5时间对齐  
**特点**：基于全国2400+台站观测的融合产品，是中国区域最准确的降水真值

**变量选择**：
- 24小时累计降水量

**预计数据量**：约20GB

### 3.3 为什么选择这两个数据源？

| 数据源 | 作用 | 优势 | 局限 |
|--------|------|------|------|
| **ERA5** | 训练输入+全球评测真值 | 全球覆盖、时间序列长、多变量 | 分辨率较粗（25km） |
| **GMCP** | 中国区域评测真值 | 基于台站观测、高分辨率（10km） | 仅覆盖中国区域 |

**互补策略**：
- ERA5用于全球范围的训练和评测（与GenCast/GraphCast/Pangu拉齐）
- GMCP用于中国区域的精细化评测（体现对国内业务的贡献）

## 六、创新点方向

### 6.1 核心创新点

#### 创新点1：物理约束扩散模型（Physics-Constrained Diffusion）
- **创新性**：首次在扩散模型中嵌入完整的大气物理约束方程
- **技术方案**：在反向扩散过程中引入水汽守恒、能量守恒等约束
- **预期贡献**：生成更符合物理规律的降水场，提升长期预报准确性
- **论文贡献度**：⭐⭐⭐⭐⭐

#### 创新点2：多尺度时空编码（Multi-Scale Spatiotemporal Encoding）
- **创新性**：使用不同时间尺度的编码器分别捕捉不同时间尺度的降水模式
- **技术方案**：3D卷积 + Transformer混合架构，1-3天、3-7天、7-15天三个尺度
- **预期贡献**：更全面地表示降水的多时间尺度特征
- **论文贡献度**：⭐⭐⭐⭐

#### 创新点3：极端事件感知分支（Extreme Event-Aware Branch）
- **创新性**：设计专门的分支网络检测和预报极端降水事件
- **技术方案**：自适应阈值检测、极端事件专用损失、多任务联合训练
- **预期贡献**：显著提升对极端降水的预报能力
- **论文贡献度**：⭐⭐⭐⭐⭐

#### 创新点4：时空异质性建模（Spatiotemporal Heterogeneity Modeling）
- **创新性**：建模降水的时空异质性，考虑不同地理位置的降水特征差异
- **技术方案**：位置感知嵌入、海拔/纬度/季节等先验特征融合
- **预期贡献**：更准确地表示不同区域的降水特征
- **论文贡献度**：⭐⭐⭐

#### 创新点5：联合概率-确定性优化（Joint Probabilistic-Deterministic Optimization）
- **创新性**：同时优化概率预测（CRPS）和确定性预测（CSI）
- **技术方案**：多任务损失函数、自适应权重调整
- **预期贡献**：兼顾预报精度和不确定性量化
- **论文贡献度**：⭐⭐⭐

## 八、风险与挑战

### 8.1 技术风险

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| 物理约束难以优化 | 模型收敛困难 | 渐进式约束、损失权重调整 |
| 极端事件样本稀少 | 模型对极端事件学习不足 | 数据增强、过采样 |
| 训练时间过长 | 迭代周期长 | 混合精度训练、模型并行 |
| 内存不足 | 无法训练大模型 | 梯度累积、模型压缩 |

### 8.2 数据风险

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| ERA5下载速度慢 | 数据准备延迟 | 分批下载、多线程 |
| 数据格式不一致 | 预处理复杂 | 统一预处理脚本 |
| 数据质量问题 | 影响模型性能 | 数据清洗、异常值处理 |

### 8.3 资源风险

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| GPU算力不足 | 训练时间过长 | 云计算、分布式训练 |
| 存储空间不足 | 无法存储数据 | 数据压缩、云存储 |
| 网络带宽限制 | 下载速度慢 | 断点续传、压缩下载 |
