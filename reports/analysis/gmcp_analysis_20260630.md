**分析时间**: 2026-07-01

**分析脚本**: `scripts/analyze_gmcp.py`

---

## 1. 数据概览

GMCP（Global Multisource Merging-and-Calibration Precipitation）是项目的主要降水标签数据源，空间分辨率 0.1°，时间分辨率 1 小时，覆盖全球。

| 指标 | 数值 |
|------|------|
| 总文件数 | 225,000 |
| 时间跨度 | 2000-01 至 2025-08 |
| 完整年份 | 2000–2024（每小时文件均完整） |
| 部分年份 | 2025（仅 1–8 月） |
| 中国区域网格 | 约 360 × 620 |
| 抽样数 | 300 个文件（覆盖 26 年） |

## 3. 数据质量控制结果

| 指标 | 数值 |
|------|------|
| 总格点数（6 小时窗口） | 66,960,000 |
| 缺失值 | 0 |
| 负值 | 0 |
| 6 小时累计 > 200 mm 的格点 | 149 |
| 6 小时最大累计降水 | 356.40 mm/6h |
| 6 小时平均累计降水 | 0.58 mm/6h |

**结论**: GMCP 数据完整性高，无缺失值、无负值。存在少量超过 200 mm/6h 的极端格点，需要在预处理阶段进行物理阈值裁剪或标记。

---

## 4. 极端降水频率

基于 300 个真实连续 6 小时窗口的统计：

| 阈值 (mm/6h) | 发生频率 |
|--------------|----------|
| ≥ 25 mm/6h（大雨） | 0.193 % |
| ≥ 50 mm/6h（暴雨） | 0.033 % |
| ≥ 100 mm/6h（大暴雨） | 0.004 % |

极端降水事件总体稀少，但高强度事件确实存在。模型训练时需要针对类别不平衡问题采用 focal loss、加权采样或单独的极端事件分支。

## 6. 主要发现

1. **数据完整性高**: 2000–2024 年每小时数据完整，覆盖训练、验证、测试所需的全部时段。
2. **数据质量总体良好**: 无缺失、无负值，但存在少量 >200 mm/6h 的极端格点，需在预处理中处理。
3. **降水分布高度偏斜**: 绝大多数格点降水接近 0，6 小时平均仅约 0.58 mm。
4. **极端事件稀少但存在**: ≥25 mm/6h 事件约占 0.19%，≥100 mm/6h 约占 0.004%，需要设计针对性的损失函数和极端分支。
5. **2025 年数据不完整**: 若计划用于训练，应截断至 2025-08-31；若仅用于测试，建议使用 2023–2024 年。

---

## 7. 下一步建议

1. **继续 ERA5 下载策略优化**: GMCP 标签已就绪，ERA5 输入仍是瓶颈；建议推进 WeatherBench2 1.5° 数据作为快速原型。
2. **生成 6 小时累计标签**: 将 GMCP 从 1 小时重采样为 6 小时累计，并保存为 Zarr 或 NetCDF。
3. **计算归一化统计量**: 在训练集（2000–2019）上计算 `log(x+1)` 的 Min-Max 参数。
4. **构建极端事件掩码**: 按 25/50/100 mm/6h 阈值生成二值掩码，用于极端分支训练。
5. **修复预处理管道兼容性**: 详见 `reports/analysis/gmcp_compatibility_fix_20260630.md`。
